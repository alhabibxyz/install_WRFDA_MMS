# Compiling ARWpost V3 with Intel Fortran

This guide describes how to compile **ARWpost V3** using the **Intel Fortran compiler** on an HPC system.

The procedure is intended for systems where WRF and its libraries are installed under a directory such as:

```bash
/home/ens_t4/install_wrf/libraries
```

> **Note:** ARWpost V3 is an old Fortran application. For this reason, **Intel Classic Fortran (`ifort`)** is generally preferred when it is available. If `ifort` is not available, `ifx` from Intel oneAPI can also be used.

---

## 1. Load the Intel Compiler Environment

If your HPC system uses Intel oneAPI directly, load the environment with:

```bash
source /opt/software/intel/oneapi/setvars.sh --force
```

Alternatively, if Intel compilers are provided through the environment module system:

```bash
module load intel
```

Check which Intel compilers are available:

```bash
which ifort
which ifx
which icx
```

Check the compiler versions:

```bash
ifort --version
ifx --version
```

If `ifort` is available, it is recommended for ARWpost V3 because of the age of the ARWpost source code.

If only `ifx` is available, `ifx` can be used instead.

---

# 2. Set WRF library environment
export DIR=/home/riset_2/install_wrf/libraries
export NETCDF=$DIR
export HDF5=$DIR
export PATH=$DIR/bin:$PATH
export LD_LIBRARY_PATH=$DIR/lib:$LD_LIBRARY_PATH

## 3. Download and Configure ARWpost

Start from the WRF installation directory:

```bash
cd ~/install_wrf
```

Remove any previous ARWpost installation if necessary:

```bash
rm -rf ARWpost
```

Download ARWpost V3:

```bash
wget https://www2.mmm.ucar.edu/wrf/src/ARWpost_V3.tar.gz
```

Extract the source:

```bash
tar -xvzf ARWpost_V3.tar.gz
```

Enter the ARWpost directory:

```bash
cd ARWpost
```

Run the configuration script:

```bash
./configure
```

When prompted, select the **Intel Fortran compiler** if it is available.
```text
Please select from among the following supported platforms.

   1.  PC Linux i486 i586 i686 x86_64, PGI compiler
   2.  PC Linux i486 i586 i686 x86_64, Intel compiler
   3.  PC Linux i486 i586 i686 x86_64, gfortran compiler

Enter selection [1-3] : 2
```

---

## 4. Configure `configure.arwp`

Open the generated configuration file:

```bash
nano configure.arwp
```

### Using Intel Classic Fortran (`ifort`)

Make sure the Fortran compiler is set to:

```make
FC = ifort
```

Do **not** keep the GNU Fortran compiler:

```make
FC = gfortran
```

The GNU Fortran flags generated by the original configuration should also be replaced.

For Intel Classic Fortran, use:

```make
FFLAGS = -O2 -FR -convert big_endian -assume byterecl
```

For the C compiler flags:

```make
CFLAGS = -fPIC -m64
```

The preprocessor can remain:

```make
CPP = /lib/cpp -P -traditional
```

Therefore, the relevant configuration should look approximately like:

```make
FC = ifort

FFLAGS = -O2 -FR -convert big_endian -assume byterecl

CFLAGS = -fPIC -m64

CPP = /lib/cpp -P -traditional
```

> **Important:** Do not simply replace `gfortran` with `ifort` while keeping GNU-specific compiler flags.

The following flags are GNU Fortran flags and should not be kept in an Intel configuration:

```text
-ffree-form
-fno-second-underscore
-fconvert=big-endian
-frecord-marker=4
-fallow-argument-mismatch
```


## 5. Configure the NetCDF Libraries in `src/Makefile`

Go to the ARWpost source directory:

```bash
cd ~/install_wrf/ARWpost/src
```

Open the Makefile:

```bash
nano Makefile
```

Make sure the NetCDF libraries are linked correctly.

Use:

```make
-L$(NETCDF)/lib -lnetcdff -lnetcdf
```

The order is important:

```text
libnetcdff
libnetcdf
```

NetCDF-Fortran depends on NetCDF-C, so `-lnetcdff` should appear before `-lnetcdf`.

The include directory should be:

```make
-I$(NETCDF)/include
```

Avoid duplicated or incorrectly ordered library flags such as:

```make
-L$(NETCDF)/lib -lnetcdf -lnetcdff -I$(NETCDF)/include -lnetcdf
```

---


## 6. Compile ARWpost

Start the compilation:

```bash
./compile
```


## 7. Final Expected Structure

After a successful compilation, the ARWpost directory should contain the executable:

```text
ARWpost/
├── configure
├── configure.arwp
├── compile
├── clean
├── src/
│   ├── ARWpost.exe
│   ├── *.o
│   └── *.mod
└── ...
```

The most important result is:

```text
ARWpost/src/ARWpost.exe
```

---

## 8. Quick Installation Summary

For an HPC system using Intel Classic Fortran, the essential workflow is:

```bash
# Load Intel environment
source /opt/intel/oneapi/setvars.sh

# Set WRF library environment
export DIR=/home/riset_2/install_wrf/libraries
export NETCDF=$DIR
export HDF5=$DIR
export PATH=$DIR/bin:$PATH
export LD_LIBRARY_PATH=$DIR/lib:$LD_LIBRARY_PATH

# Download ARWpost
cd ~/install_wrf
rm -rf ARWpost

wget https://www2.mmm.ucar.edu/wrf/src/ARWpost_V3.tar.gz
tar -xvzf ARWpost_V3.tar.gz

# Configure
cd ARWpost
./configure

# Edit configure.arwp
nano configure.arwp

# Edit NetCDF linking
nano src/Makefile

# Clean previous build
./clean
rm -f src/*.o
rm -f src/*.mod
rm -f src/*.f
rm -f src/ARWpost.exe

# Compile
./compile

# Verify
ls -lh src/ARWpost.exe
```

## Recommended Compiler Choice

For **ARWpost V3**, the recommended order is:

1. **Intel Classic Fortran (`ifort`)** — preferred for this legacy code.
2. **Intel oneAPI Fortran (`ifx`)** — usable if `ifort` is unavailable.
3. **GNU Fortran (`gfortran`)** — also possible, but requires GNU-specific compiler flags and configuration.

For consistency, it is generally preferable to compile ARWpost with a compiler compatible with the compiler environment used for the WRF installation.
