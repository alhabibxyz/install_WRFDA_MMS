## Compile WRFPLUS 4.7.1

WRFPLUS is compiled using the Intel Classic compiler with Intel MPI in the MMS environment.

```bash
cd ~/install_wrf

# Clone WRFPLUS source
git clone --recurse-submodule https://github.com/wrf-model/WRF.git WRFPLUS

cd WRFPLUS

# Checkout WRF 4.7.1
git checkout v4.7.1

# Initialize/update submodules
git submodule update --init --recursive

git status
git describe --tags --exact-match HEAD

# Clean previous build
./clean -aa
```

Set the library and compiler environment:
```bash
export DIR=$HOME/install_wrf/libraries

export NETCDF=$DIR
export HDF5=$DIR

export PATH=$NETCDF/bin:$PATH

export INTEL_LIB=/opt/software/intel/oneapi/compiler/2022.0.2/linux/compiler/lib/intel64_lin
export LD_LIBRARY_PATH="$INTEL_LIB:$NETCDF/lib"

# Use Intel Classic compiler + Intel MPI
export FC=ifort
export CC=icc
export F90=ifort

export DM_FC=mpiifort
export DM_CC=mpiicc

# Use clean archiver and ranlib wrappers
export AR="$HOME/bin/ar-clean"
export RANLIB="$HOME/bin/ranlib-clean"
```
Configure WRFPLUS:

```bash
./configure wrfplus
```
Select the Intel Classic compiler, dmpar (8) option corresponding to your WRF configuration.
After configuration, check:
```bash
grep -nE '^(SFC|SCC|DM_FC|DM_CC|FC|CC)' configure.wrf
```
If configure.wrf generates mpif90 and mpicc, replace them with Intel MPI Classic:
```bash
cp configure.wrf configure.wrf.before-mms-fix

sed -i 's/^DM_FC[[:space:]]*=.*/DM_FC           = mpiifort -f90=$(SFC)/' configure.wrf
sed -i 's/^DM_CC[[:space:]]*=.*/DM_CC           = mpiicc -cc=$(SCC)/' configure.wrf
```
Check the result:
```bash
grep -nE '^(SFC|SCC|DM_FC|DM_CC|FC|CC)' configure.wrf
```

Compile WRFPLUS:
```bash
./compile -j 4 wrfplus 2>&1 | tee wrfplus.compile.log
```

Check the executable:
```bash
ls -lh main/wrfplus.exe
```
A successful build should produce:
```bash
main/wrfplus.exe
```
