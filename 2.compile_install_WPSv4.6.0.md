# Compile WPS 4.6.0 with Intel oneAPI / MMS Environment

This guide describes how to compile **WPS 4.6.0** using the same Intel oneAPI / Intel MPI environment that was successfully used to compile WRF 4.7.1.

The tested compiler environment is:

- Intel oneAPI Compiler 2022.0.2
- Intel Fortran Compiler (ifort) 2021.5.0
- Intel C Compiler (icc) 2021.5.0
- Intel MPI 2021.5.1
- WRF 4.7.1
- WPS 4.6.0
- NetCDF / NetCDF-Fortran installed under `$HOME/install_wrf/libraries`

---

```bash
cd ~/install_wrf

# Download WPS 4.6.0
wget https://github.com/wrf-model/WPS/archive/refs/tags/v4.6.0.tar.gz

# Extract
tar -xvf v4.6.0.tar.gz

# Rename directory
mv WPS-4.6.0 WPS

cd WPS

# Clean previous build
./clean

# Configure WPS
./configure
```
When the compiler options appear, select:
```text
23. Linux x86_64, Intel Classic compilers (dmpar)
```

Then change the MPI compiler wrapper to use Intel MPI Classic:
```bash
cp configure.wps configure.wps.before-mms-fix

sed -i 's/^DM_FC[[:space:]]*=.*/DM_FC               = mpiifort/' configure.wps
sed -i 's/^DM_CC[[:space:]]*=.*/DM_CC               = mpiicc/' configure.wps
```
Check:
```bash
grep -nE '^(SFC|SCC|DM_FC|DM_CC|FC|CC)' configure.wps
```
Expected output:
```text
SFC                 = ifort
SCC                 = icc
DM_FC               = mpiifort
DM_CC               = mpiicc
FC                  = $(DM_FC)
CC                  = $(DM_CC)
```

compiler check:
```bash
which ifort
which icc
which mpiifort
which mpiicc

mpiifort --version | head -3
mpiicc --version | head -3
```

Set the WRF and library environment::
```bash
export DIR=$HOME/install_wrf/libraries

export NETCDF=$DIR

export JASPER=$DIR
export JASPERLIB=$DIR/lib
export JASPERINC=$DIR/include

export ZLIB=$DIR
export ZLIBLIB=$DIR/lib
export ZLIBINC=$DIR/include

export PNG=$DIR
export PNGLIB=$DIR/lib
export PNGINC=$DIR/include

export WRF_DIR=$HOME/install_wrf/WRF

export INTEL_LIB=/opt/software/intel/oneapi/compiler/2022.0.2/linux/compiler/lib/intel64_lin

export PATH=$NETCDF/bin:$PATH
export LD_LIBRARY_PATH="$INTEL_LIB:$NETCDF/lib"

# Use clean archiver and ranlib wrappers
export AR="$HOME/bin/ar-clean"
export RANLIB="$HOME/bin/ranlib-clean"
```

Compile WPS:
```bash
./compile 2>&1 | tee compile.wps.log
```
Verify:
```bash
ls -lh geogrid.exe metgrid.exe ungrib.exe
```

expected output:
```text
geogrid.exe
metgrid.exe
ungrib.exe
```
