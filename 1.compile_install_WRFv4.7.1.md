## WRF 4.7.1 Installation and Compilation on MMS Environment

This document describes the installation and compilation of **WRF 4.7.1** on the MMS HPC environment using the Intel oneAPI compiler and Intel MPI.

The procedure below was tested successfully with:

- WRF: `4.7.1`
- Intel oneAPI Compiler: `2022.0.2`
- Intel Fortran Compiler: `ifort 2021.5.0`
- Intel C Compiler: `icc 2021.5.0`
- Intel MPI: `2021.5.1`
- NetCDF-Fortran: `4.6.2`
- Linux: Rocky/RHEL 8 compatible environment

The final compilation successfully produced:

```text
main/ndown.exe
main/real.exe
main/tc.exe
main/wrf.exe
```

# 1. Load / prepare the Intel oneAPI environment
Make sure the Intel oneAPI compiler and Intel MPI environment are available.

Check the compiler:
```bash
which ifort
which icc
which mpiifort
which mpiicc
```
expected:
```text
/opt/software/intel/oneapi/compiler/2022.0.2/linux/bin/intel64/ifort
/opt/software/intel/oneapi/compiler/2022.0.2/linux/bin/intel64/icc
/opt/software/intel/oneapi/mpi/2021.5.1/bin/mpiifort
/opt/software/intel/oneapi/mpi/2021.5.1/bin/mpiicc
```
Check versions:
```bash
ifort --version | head -3
icc --version | head -3
mpiifort --version | head -3
mpiicc --version | head -3
```
Expected:
```text
ifort (IFORT) 2021.5.0 20211109
icc (ICC) 2021.5.0 20211109
```
# 2. Define the WRF library directory and NetCDF environment variables
In this installation, all external WRF libraries and NetCDF env are installed under:
```bash
export DIR=$HOME/install_wrf/libraries
export NETCDF=$DIR

export PATH=$NETCDF/bin:$PATH
```

# 3. Important MMS Intel runtime environment
```bash
export INTEL_LIB=/opt/software/intel/oneapi/compiler/2022.0.2/linux/compiler/lib/intel64_lin
export LD_LIBRARY_PATH="$INTEL_LIB:$DIR/lib"
```
# 4. Download WRF 4.7.1
Create the WRF installation directory:

```bash
mkdir -p $HOME/install_wrf
cd $HOME/install_wrf
```
Clone the WRF repository and checkout WRF 4.7.1:
```bash
git clone https://github.com/wrf-model/WRF.git WRF
cd WRF
git checkout v4.7.1
git submodule update --init --recursive
git describe --tags --always
```
# 5. Clean and configure the WRF source tree
Before configuration:
```bash
cd $HOME/install_wrf/WRF
./clean -aa
./configure
```
The WRF configure menu will appear.
For the MMS Intel oneAPI environment, select 15 and For the nesting option select 1, 
```bash
13. (serial)  14. (smpar)  15. (dmpar)  16. (dm+sm)   INTEL (ifort/icc)
Enter selection [1-83] : 15
Compile for nesting? (1=basic, 2=preset moves, 3=vortex following) [default 1]: 1
```
# 6. Adjust configure.wrf

```bash
sed -i 's#^DM_FC.*#DM_FC           =       mpiifort#g' configure.wrf
sed -i 's#^DM_CC.*#DM_CC           =       mpiicc#g' configure.wrf
```
check:
```bash
grep -nE '^(SFC|SCC|CCOMP|DM_FC|DM_CC|FC|CC)' configure.wrf
```
must like this:
```text
SFC             =       ifort
SCC             =       icc
CCOMP           =       icc
DM_FC           =       mpiifort
DM_CC           =       mpiicc
FC              =       time $(DM_FC)
CC              =       $(DM_CC) -DFSEEKO64_OK
```

# 7. MMS-specific ar segmentation fault problem

During the WRF build on MMS, the Intel runtime library can interfere with GNU binutils.

With:
```bash
export LD_LIBRARY_PATH="$INTEL_LIB:$DIR/lib"
```
running /usr/bin/ar can produce:
```text
ar: Relink `/opt/software/intel/oneapi/compiler/2022.0.2/linux/compiler/lib/intel64_lin/libimf.so' with `/lib64/libm.so.6' for IFUNC symbol `sinf'
Segmentation fault (core dumped)
```

This is an environment/runtime-library conflict between GNU ar and Intel's libimf.so.

The same problem can occur with ranlib.

Therefore, create clean wrapper scripts that temporarily remove the Intel runtime library path before executing ar and ranlib.
# 8. Create a clean ar wrapper

Create:
```bash
mkdir -p $HOME/bin
```
Then:
```bash
cat > "$HOME/bin/ar-clean" <<'EOF'
#!/bin/bash
unset LD_LIBRARY_PATH
unset LD_PRELOAD
unset LIBRARY_PATH
exec /usr/bin/ar "$@"
EOF
```
Make it executable:
```bash
chmod +x "$HOME/bin/ar-clean"
```
Set:
```bash
export AR="$HOME/bin/ar-clean"
```
Test:
```bash
$AR --version | head -1
```
Expected:
```text
GNU ar version 2.30-128.el8_10
```

Test the wrapper:
```bash
rm -f /tmp/test_ar.a /tmp/test_ar.o

cat > /tmp/test_ar.c <<'EOF'
int test_ar(void) { return 0; }
EOF

gcc -c /tmp/test_ar.c -o /tmp/test_ar.o

$AR cr /tmp/test_ar.a /tmp/test_ar.o

echo "ar_exit=$?"
ls -lh /tmp/test_ar.a
```

Expected:

ar_exit=0
# 9. Create a clean ranlib wrapper

Create:

```bash
cat > "$HOME/bin/ranlib-clean" <<'EOF'
#!/bin/bash
unset LD_LIBRARY_PATH
unset LD_PRELOAD
unset LIBRARY_PATH
exec /usr/bin/ranlib "$@"
EOF
```

Make it executable:
```bash
chmod +x "$HOME/bin/ranlib-clean"
```
Set:
```bash
export RANLIB="$HOME/bin/ranlib-clean"
```
Test:
```bash
$RANLIB --version | head -1
```
Expected:
```text
GNU ranlib version 2.30-128.el8_10
```

# 10. Patch WRF's libtool to use clean ar and ranlib

The WRF build system may hard-code:
```text
/usr/bin/ar
```

and:
```text
/usr/bin/ranlib
```

Therefore, simply exporting AR and RANLIB is not always sufficient.

Go to the WRF directory:

```bash
cd $HOME/install_wrf/WRF
```

Back up the generated libtool:
```bash
cp libtool libtool.before-ar-ranlib-fix
```

Replace /usr/bin/ar:
```bash
sed -i "s#AR='/usr/bin/ar'#AR='$HOME/bin/ar-clean'#g; s#AR=\"/usr/bin/ar\"#AR=\"$HOME/bin/ar-clean\"#g" libtool
```
Replace /usr/bin/ranlib:
```bash
sed -i "s#RANLIB='/usr/bin/ranlib'#RANLIB='$HOME/bin/ranlib-clean'#g; s#RANLIB=\"/usr/bin/ranlib\"#RANLIB=\"$HOME/bin/ranlib-clean\"#g" libtool
```

Verify:
```bash
grep -nE '^(AR|RANLIB)=' libtool
```

Expected:
```text
AR="/home/riset_2/bin/ar-clean"
RANLIB="/home/riset_2/bin/ranlib-clean"
```

The exact home directory will depend on the user account.

# 11. Export the final build environment
Before compilation:
```bash
export DIR=$HOME/install_wrf/libraries
export NETCDF=$DIR

export PATH=$NETCDF/bin:$PATH

export INTEL_LIB=/opt/software/intel/oneapi/compiler/2022.0.2/linux/compiler/lib/intel64_lin
export LD_LIBRARY_PATH="$INTEL_LIB:$DIR/lib"

export AR="$HOME/bin/ar-clean"
export RANLIB="$HOME/bin/ranlib-clean"
```
Check:

```bash
echo "NETCDF=$NETCDF"
echo "PATH=$PATH"
echo "LD_LIBRARY_PATH=$LD_LIBRARY_PATH"

which ifort
which icc
which mpiifort
which mpiicc

which nc-config

$AR --version | head -1
$RANLIB --version | head -1
```
# 12 Compile WRF
Compile the real-data case:
```bash
cd $HOME/install_wrf/WRF
./compile -j 4 em_real >& compile.log
```
Monitor the compilation from another terminal:
```bash
tail -f compile.log
```
Verify successful compilation:
```text
--->                  Executables successfully built                  <---
```
For em_real, the important executables are:
```bash
ls -lh main/wrf.exe
ls -lh main/real.exe
ls -lh main/ndown.exe
ls -lh main/tc.exe
```
Expected files:
```text
main/wrf.exe
main/real.exe
main/ndown.exe
main/tc.exe
```
